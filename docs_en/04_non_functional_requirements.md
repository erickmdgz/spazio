# Non-functional requirements

## NFR-001 - Password security

Passwords must be stored using secure hashing.

## NFR-002 - Protected access

Private routes must not be accessible without authentication.

## NFR-003 - Usability

The user must be able to complete the main flow without technical training.

## NFR-004 - Performance

The main views must load within a reasonable time for a simple application.

## NFR-005 - Maintainability

The code must be organized into modules and include clear installation instructions.

## NFR-006 - Traceability

Every new feature must be linked to a requirement, issue, test, and pull request.
